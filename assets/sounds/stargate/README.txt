Optional custom Stargate sounds
===============================

The game synthesizes all Stargate and hyperspace sounds itself. If you have your own
recordings you'd like to use instead, put mp3 files here with these exact names, and list
the names you added in manifest.json (for example ["chevron", "kawoosh"]). The game will
play them in place of the synthesized versions:

  dhd_press.mp3     a DHD key being pressed
  dhd_dome.mp3      the centre dome being pressed
  dial_fail.mp3     an invalid address
  gate_spin.mp3     the inner ring turning (looped while dialling)
  chevron.mp3       a chevron locking
  kawoosh.mp3       the wormhole forming
  horizon.mp3       an open event horizon (looped)
  wormhole.mp3      travelling through the wormhole
  gate_close.mp3    the wormhole shutting down
  hyper_open.mp3    a hyperspace window opening
  hyper_travel.mp3  travelling in hyperspace (looped)
  hyper_exit.mp3    dropping out of hyperspace

Only use audio you have the right to use.
